# T-AGNET 手机端需求

目标平台：Android。手机是交互、审批和配置客户端，不运行 Pi 或本地 MCP 进程。

## 完整架构

请先阅读本目录的 [ARCHITECTURE.md](ARCHITECTURE.md)。三个端均保存同一份完整架构，本文补充手机端职责与实施清单。

## 技术栈

- Kotlin + Jetpack Compose。
- ViewModel + Coroutines/StateFlow。
- Room：共享数据缓存、待发送队列；DataStore：偏好。
- OkHttp：HTTPS 与前台 WebSocket。
- WorkManager：可延迟的后台同步与失败重试。
- 凭据通过 Android Keystore 支持的加密存储处理。
- FCM 可选；首版不依赖 Google Play 服务实现基本功能。

## 页面与功能

### 会话与聊天

- 会话列表、创建会话、历史加载、搜索、流式云端回复。
- 明确选择云端问答或某台 Mac 的本地任务；本地编程还需选择项目。
- 同一会话可以切换执行端，展示每次运行的位置和状态。
- 显示共享聊天，私有代码详情显示“在 Mac 查看”，不伪装为全文同步。
- 本地代码任务不接收 Pi 原始工具流，展示已发布的计划与执行摘要。

### 项目与设备

- 项目名称、所属 Mac、在线状态、最后同步时间。
- 手机不输入或覆盖 Mac 真实路径，不浏览本机任意文件树。
- Mac 离线仍可提交计划请求，明确显示排队；不承诺唤醒休眠 Mac。

### Plan 审阅

- 展示目标、范围、步骤、影响模块、验证方案、权限需求和版本。
- 操作：批准并执行、要求修改、拒绝、取消。
- 审批携带 plan_id/version/hash，与服务端最新版本一致。
- 修改意见发送到 Mac，等待 Pi 生成新版本；不能只改 UI 文本就执行。
- 重复点击防抖与幂等键；收到服务端确认才显示批准成功。
- 离线可保存意见草稿；审批必须在线重新校验并确认。

### 执行监控

- 展示 queued、waiting_for_device、planning、awaiting_review、running、等待输入、完成、失败和取消。
- 展示步骤进度、工具名称与简要结果、测试摘要和本地成果引用。
- 支持补充要求、取消；设备离线时取消显示待送达，不能立即宣告已停止。
- 登录、验证码或系统权限要求本机处理时显示 waiting_for_local_action。
- 标记状态是否陈旧；不把设备断网解释成任务失败。
- 首版不做源码编辑器、完整 diff 浏览和手机终端。

### 配置管理

- 模型：查看/编辑 provider、地址、model_id、默认用途与执行位置；显示凭据是否已配置。
- Skills：列表、内容与版本、启停、编辑、执行环境、应用状态；local_only 内容不可读取。
- MCP：模板、命令/URL、工具启停、执行环境、连接状态和错误。
- 本机秘密默认不下载到手机；机器路径在 Mac 绑定，手机展示缺少绑定状态。
- 配置保存使用 expected_version，冲突时展示差异；desired_version 与 applied_version 分开显示。
- 保存配置不代表该执行端已成功应用，也不触发任意依赖安装脚本。

## 离线与同步

- Room 是 UI 数据入口，网络结果先进入本地数据层。
- 前台 WSS 实时更新，重连按 server_cursor 拉取增量，event_id 去重。
- 离线浏览缓存及时间戳，待发消息有明确状态与幂等 ID。
- WorkManager 做后台补同步，不承诺永久连接或秒级后台通知。
- 恢复网络后先对账，再刷新审批和任务状态。
- 多端同时修改配置采用服务端版本校验；不得按手机本地时间静默覆盖。

## 对外契约

输入：云端共享消息、项目与设备目录、计划版本、执行事件、配置版本及应用结果。
输出：消息/任务请求、审批/修改意见、取消/补充输入、配置修改。
手机不直接连接 Pi、不直接连接 Chrome 调试端口、不发送任意 shell RPC。

## 首批开发任务

1. 建立 Compose 导航、Room、认证和 API 客户端。
2. 完成项目选择、计划请求、审阅并执行流程。
3. 完成任务卡片、事件回放、缓存与状态陈旧提示。
4. 完成云端 DeepAgents 聊天、执行位置切换。
5. 模型/Skills/MCP 配置页面与冲突处理（Skills/MCP 已实现，见 ../CONFIGS.md）；可选推送。

## 重点验收

- 能在手机完成“选项目—请求 Plan—审阅—批准执行—看结果”。
- 重复点击不会重复执行，旧计划不能批准，离线不会显示审批成功。
- 关闭手机应用后任务继续，重开后历史和状态补齐。
- Mac 断线时展示最后状态和时间，远程取消显示待送达。
- 代码详情留在 Mac，共享计划与执行摘要保持一致。
